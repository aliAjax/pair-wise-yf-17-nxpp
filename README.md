# 管风琴音管调音续作台

给管风琴维护人员使用的音管调音记录前端：音栓台账、音分偏差、温湿度观测、异常标记与年度维护报告一体化，支持弱网/断网环境下的离线登记与总档合并。

## 核心机制

- **离线登记**：断网照常登记调音记录与温湿度观测，数据持久化在本地（localStorage），恢复网络后自动补传。
- **逐字段合并**：回传时按音管编号定位总档记录，以「上次同步值」为基准做逐字段三方合并——仅本地改过 → 总档采用本地；仅总档改过 → 本地采纳总档；**两边改过同一字段 → 保留两版，等人工确认**（采用本地 / 采用总档）。
- **幂等回传**：每根音管的每次修改生成幂等键（`音管编号#r版本号`），上传失败保住已完成部分，恢复后只补未同步的音管；回执丢失导致的重复回传不会生成第二份记录。
- **统一补偿口径**：音栓台账与温湿度观测共用同一套补偿标准（`src/domain/compensation.ts`）——基准温度 T₀（默认 20°C），每偏离 1°C 音分偏移 2.0 cent，补偿后偏差 = 实测音分 − 2.0 × (观测温度 − T₀)。
- **基准温度联动**：基准温度一变，全部音分偏差立即作废重算，已确认的维护报告自动退回「待复核」。

## 目录结构

```
src/
  domain/
    compensation.ts  # 统一补偿口径（常量 + 计算函数 + 说明文案）
    types.ts         # 领域类型
    seed.ts          # 种子数据（本地与模拟总档共用）
    master.ts        # 模拟总档：逐字段三方合并 + 幂等键
  hooks/
    useWorkbench.ts  # 工作台状态与弱网同步引擎
  App.tsx            # 界面
```

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62005

## 演示路径

1. 初始有两根音管「待回传」，点「回传总档」；弱网模拟开启时可能失败，已完成部分保留，再点一次只补未同步的。
2. 点「模拟断网」后登记新音管，再「恢复网络」，会自动补传。
3. 编辑一根已同步音管的某字段，点「模拟另一调音师回传」（对方改了同一字段），再回传 → 出现冲突卡片，留两版等确认。
4. 修改基准温度 → 偏差表立即重算，St.Mary 已确认年报退回「待复核」。
